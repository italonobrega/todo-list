# ✅ To-Do List

Aplicativo de lista de tarefas desenvolvido com HTML, CSS e JavaScript puro.

**[👉 Clique aqui para acessar o site](https://italonobrega.github.io/todo-list/)**

## ✨ Funcionalidades

- Adicionar tarefas
- Concluir e reabrir tarefas
- Deletar tarefas
- Filtrar por: Todas, Ativas e Concluídas
- Contador de tarefas pendentes
- Dados salvos no `localStorage` — as tarefas persistem após recarregar a página
